# Glance Requirements Specification

## 1. Project Overview

Glance เป็นระบบติดตามข้อมูลส่วนบุคคล (Personal Tracking System) ที่ช่วยให้ผู้ใช้งานสามารถกำหนดรายการติดตาม บันทึกข้อมูล วิเคราะห์แนวโน้ม และค้นหาความสัมพันธ์ของพฤติกรรมจากข้อมูลที่บันทึกไว้ โดยมีเป้าหมายเพื่อช่วยให้ผู้ใช้งานเข้าใจรูปแบบการใช้ชีวิตของตนเองผ่านข้อมูลและข้อมูลเชิงลึกที่สร้างขึ้นด้วยปัญญาประดิษฐ์

---

## 4. Core Concepts

### 4.1 Metric

Metric คือรายการติดตามที่ผู้ใช้งานกำหนดขึ้น

ตัวอย่าง:

- Sleep Hours
- Stress Level
- Energy Level
- Exercise
- Meditation
- Reading Time

ระบบรองรับ Metric 6 ประเภท

1. Boolean
2. Number
3. Rating
4. Single Select
5. Multiple Select
6. Text

---

### 4.2 Record

Record คือข้อมูลที่ผู้ใช้งานบันทึกสำหรับ Metric แต่ละรายการ

ตัวอย่าง:

Metric: Meditation

- 09:00 → 5 นาที
- 14:00 → 10 นาที
- 20:00 → 15 นาที

ระบบต้องรองรับการบันทึกข้อมูลหลายรายการภายในวันเดียวกัน

---

### 4.3 Goal

Goal คือเป้าหมายที่ผู้ใช้งานกำหนดให้กับ Metric

ตัวอย่าง:

- Meditation ≥ 30 นาทีต่อวัน
- Exercise ≥ 3 ครั้งต่อสัปดาห์

---

### 4.4 Dashboard

Dashboard เป็นหน้าสรุปข้อมูลที่ช่วยให้ผู้ใช้งานสามารถติดตามแนวโน้ม ความสัมพันธ์ และข้อมูลเชิงลึกของข้อมูลที่บันทึกไว้

---

| BR-09 | ผู้ใช้งานต้องได้รับประสบการณ์การใช้งานที่สะดวก รวดเร็ว และเหมาะสมต่อการบันทึกข้อมูลอย่างต่อเนื่อง         |

## 6. Functional Requirements

### FN-01 การสมัครสมาชิกและเข้าใช้งาน

- FR-01.01 ระบบต้องรองรับการสมัครสมาชิกโดยใช้อีเมล
- FR-01.02 ระบบต้องรองรับการเข้าใช้งานด้วยอีเมลและรหัสผ่าน
- FR-01.03 ระบบต้องรองรับการออกจากระบบ
- FR-01.04 ระบบต้องรองรับการเปลี่ยนรหัสผ่าน

### FN-02 การเข้าใช้งานครั้งแรก

- FR-02.01 ระบบต้องแสดงคำแนะนำการใช้งานฟีเจอร์หลักสำหรับผู้ใช้งานที่เข้าใช้งานครั้งแรก
- FR-02.02 ระบบต้องรองรับการข้ามคำแนะนำการใช้งาน

### FN-04 การจัดการรายการติดตาม

- FR-04.01 ระบบต้องรองรับการสร้างรายการติดตาม
- FR-04.02 ระบบต้องรองรับการแก้ไขรายการติดตาม
- FR-04.03 ระบบต้องรองรับการลบรายการติดตาม
- FR-04.04 ระบบต้องสามารถแสดงรายการติดตามตัวอย่าง (Starter Metrics) สำหรับช่วยให้ผู้ใช้งานเริ่มต้นกำหนดรายการติดตามได้
- FR-04.05 ระบบต้องรองรับรายการติดตาม 6 ประเภท ได้แก่ Boolean, Number, Rating, Single Select, Multiple Select และ Text
- FR-04.06 ระบบต้องรองรับการกำหนดหน่วยสำหรับรายการติดตามประเภท Number
- FR-04.07 ระบบต้องรองรับการกำหนดค่าต่ำสุดและสูงสุดสำหรับรายการติดตามประเภท Rating
- FR-04.08 ระบบต้องรองรับการกำหนดตัวเลือกสำหรับรายการติดตามประเภท Single Select และ Multiple Select
- FR-04.09 ระบบต้องรองรับการจัดกลุ่มรายการติดตาม
- FR-04.10 ระบบต้องถามยืนยันผู้ใช้งานก่อนลบรายการติดตาม
- FR-04.11 ระบบต้องรองรับการเปิดใช้งานหรือปิดใช้งานรายการติดตาม

### FN-05 การบันทึกรายการติดตาม

- FR-05.01 ระบบต้องแสดงวันที่ปัจจุบันเป็นค่าเริ่มต้นในหน้าบันทึกรายการติดตาม
- FR-05.02 ระบบต้องรองรับการบันทึกข้อมูลย้อนหลัง
- FR-05.03 ระบบต้องไม่อนุญาตให้บันทึกข้อมูลในวันที่อนาคต
- FR-05.04 ระบบต้องบันทึกวันที่และเวลาของข้อมูลที่ผู้ใช้งานระบุ โดยกำหนดวันที่ปัจจุบันเป็นค่าเริ่มต้น
- FR-05.05 ระบบต้องรองรับการแก้ไขข้อมูลที่บันทึกไว้
- FR-05.06 ระบบต้องรองรับการลบข้อมูลที่บันทึกไว้
- FR-05.07 ระบบต้องรองรับการบันทึกหมายเหตุประกอบข้อมูลรายการติดตาม โดยไม่บังคับให้ผู้ใช้งานกรอกหมายเหตุ
- FR-05.08 ระบบต้องรองรับการบันทึกข้อมูลของรายการติดตามเดียวกันได้มากกว่าหนึ่งรายการภายในวันเดียวกัน

## 7. Non-Functional Requirements

### Security

- NFR-09.01 ระบบต้องจัดเก็บรหัสผ่านของผู้ใช้งานในรูปแบบที่ไม่สามารถเรียกคืนเป็นรหัสผ่านเดิมได้
- NFR-10.01 ระบบต้องแสดงเฉพาะข้อมูลของผู้ใช้งานที่เข้าสู่ระบบอยู่

### Data Integrity

- NFR-11.01 ระบบต้องรักษาความถูกต้องและความสอดคล้องของข้อมูล

### Performance

- NFR-14.01 ระบบควรตอบสนองต่อการดำเนินการทั่วไปของผู้ใช้งานภายในระยะเวลาที่เหมาะสม โดยไม่ทำให้การใช้งานตามปกติเกิดความล่าช้าที่สังเกตได้

### Usability

- NFR-15.01 ระบบควรออกแบบกระบวนการบันทึกข้อมูลให้ผู้ใช้งานสามารถดำเนินการได้อย่างสะดวกและใช้จำนวนขั้นตอนที่เหมาะสม

## 8. AI Analysis Guidelines

AI Analysis ต้องมุ่งเน้นการวิเคราะห์จากข้อมูลที่ผู้ใช้งานบันทึกไว้จริง และต้องสามารถอธิบายที่มาของผลลัพธ์ได้

ตัวอย่างการวิเคราะห์:

- แนวโน้ม (Trend Analysis)
- ความสัมพันธ์ระหว่างรายการติดตาม (Correlation Analysis)
- เปรียบเทียบข้อมูลกับเป้าหมายที่กำหนดไว้
- สรุปพฤติกรรมที่พบจากข้อมูลย้อนหลัง

AI ต้องไม่สรุปความสัมพันธ์เชิงเหตุและผลจากข้อมูลที่ไม่สามารถรองรับข้อสรุปดังกล่าวได้
